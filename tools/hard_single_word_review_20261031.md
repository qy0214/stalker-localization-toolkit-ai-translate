# 单字俄文 canon 逐条审查（2026-10-31）

## 结论

对 hard canon 里的 **349 个单字俄文词**逐条统计了语料出现次数、大小写、
引号内/外和上下文样例，采用“该留则留、该降则降、该限语境则限”的方式：

| 决策 | 数量 |
|---|---:|
| 保留 hard（专名/宇宙术语/译名稳定） | 309 |
| 加首字母大小写语境限制 | 31 |
| 降为 reference 软提示 | 8 |
| 修正译名后保留 | 1 |

审查后 canon 1,451 / names 3,069 / technical 18 / reference 4,509，
总数仍是 9,047；回归 332 项全过。

## 保留 hard 的依据

单字但属于游戏宇宙术语、专有地名、怪物名，或译名稳定且没有普通名词歧义：

- `Артефакт`（903 次，神器）—— 全游戏通用术语；
- `ПДА`（754 次，PDA）—— 设备名；
- `Зоне/Зоны/Зону`（657/558/226 次，禁区）—— 游戏核心地名；
- `Тайник`（474 次，藏匿点）—— 任务/物品通用术语；
- `ЧАЭС`（201 次，切尔诺贝利核电站）—— 专名；
- `Кордон`、`Припять`、`Янтарь`、`Агропром`、`Лиманск` 等地点名；
- `Кровосос`、`Контролёр`、`Химера`、`Псевдогигант` 等怪物名。

这些词在语境里不会变成另一个普通含义，保留 hard 能保证全篇统一。

## 降为软提示的 8 条

普通物品名，目标译名是常见名词，模型用“电视/纸条/急救包/探测仪”等
自然同义词时不应算缺失，也不该强制精确替换：

- `Записка/Записки/Записку` → 便条；
- `Аптечка/Аптечки/Аптечку` → 医疗包；
- `Детектор` → 探测器；
- `Телевизор` → 电视机。

它们仍会在正文精确命中时作为提示出现，只是不强制。

## 加语境限制的 31 条

- 阵营/成员形式（`Долга/Монолита/Свободы/...`）继续只认引号内专名；
- `Свалка/Свалке/Свалки/Свалку`、`Завод/Болото/Пещера/Тоннель` 及表单
  改为首字母大小写敏感：大写地名仍译“废料场/工厂/沼泽/洞穴/隧道”，
  小写普通名词交给模型；
- 人物名与其他专名继续由 names 层首字母策略处理。

## 修正后保留

- `Изоморф`：原“同形物”按 NS7 官方改为 **同形体**；复数 `Изоморфы`
  原本就是“同形体”，现在单复数一致。

## 审查方法与边界

逐条统计写在 `tools/hard_single_word_audit_20261031.csv`，包含：

- 分类、原文、译名、总出现次数、语料中实际小写次数；
- 引号内/紧贴引号次数；
- 决策（keep_hard / case_gated / demote_generic_item / fixed_and_kept）；
- 一条原文样例。

边界：

- 单字词的“普通名词/专名”判断仍有人工成分；本次只对能明确举出普通语境
  的词做降级/限制，没有把所有 309 个保留词一概而论。
- 下一步如果仍发现误伤，优先看 CSV 里 `keep_hard` 且小写占比高的词，
  逐个加语境，而不是整层降软。
