## 0. 一页结论

1. **最高优先级阻断项不是控件，是 import**：2.x 发行包剥掉了 `_ssl.pyd` / `libssl` / `libcrypto`，而插件第 37–39 行 `import urllib.request` 会连带 `import ssl` ⇒ **2.x 下连加载都失败**。必须先替换网络层（自实现 WinHTTP，ctypes），否则后面所有适配都跑不到。
2. **控件门面可以做"零侵入适配"**：插件实际只用了 14 个 `api.ui` 方法（`pack` 81 次、`button` 21、`label` 19、`row` 18、`set_state` 16、`checkbox` 9、`combo` 7、`drop_box` 3、`ask_yes_no` 3、`ask_open_file` 3、`entry` 2、`text_view` 1、`text` 1、`ask_save_file` 1）。2.x 是这 14 个方法的**超集**，差异点有限且可枚举 ⇒ 写一层 `UiAdapter` + `WidgetProxy`，**插件主体 7,559 行基本不用改**。
3. **`row()` 在 2.x 下不能直接用**（实测代码路径：`place()` 只认 `QVBoxLayout`，给 `row()` 的 `QHBoxLayout` 再 `new QVBoxLayout` 会被 Qt 拒绝安装 ⇒ 子控件全叠在 (0,0)）。适配层的做法是**让 2.x 的 `row()` 直接返回 parent**，子控件自然落进页面纵向布局；代价是"一行多控件"变成纵向堆叠（见 §7 风险 R2）。
4. **线程模型必须改**：2.x 有 UI 线程闸门，工作线程调 `ui.*` **不抛异常、返回 `None`** 并记 Warn。现有 `ui_call` 在 `_tk is None` 时**同步执行**，2.x 下这条会把控件操作留在 worker ⇒ 静默变 None。必须改成"非 UI 线程一律入队 + `ui.timer` 泵"。
5. **`combo` 没有"选中索引"写入口**（`combo_set_items` 固定第 0 项为当前项）⇒ 用"把目标项轮转到首位"绕行；不改上游、不提 issue（沿用既定口径）。


语义要点（`plugin_ui.cpp` / `widget_facade_qt.cpp`）：

- **所有构造方法内部都会 `place(parent, child)`**（自动挂进父容器纵向布局）；`pack` 只是"改顺序/拉伸"的补充手段。
- `place()` 只认 `QVBoxLayout`；**对 `row()`（`QHBoxLayout`）会新建一个装不上的 `QVBoxLayout`** ⇒ 子控件失去几何管理。**`row()` 在 2.x 下不可用于承载子控件。**
- `place()` 有"**上一个控件是 QLabel、这一件是 QLineEdit ⇒ 并成一行**"的自动配对。`drop_box` 就是只读 `QLineEdit` ⇒ "输入：/输出：/模型："这三行能自动成行。
- `set_text` 支持 `QLabel/QPushButton/QLineEdit/QPlainTextEdit`（**不支持 QComboBox**）；`get_text` 额外支持 `QComboBox`。
- `alive()` 是**真判活**（登记过句柄走 `QPointer`）；`plugin_ui.cpp` 里的 C ABI `ui_alive` 才是"只判非空"。
- `ask_open_file` 的 `filetypes` 接受 **1.x 那种两元组列表**（`[("GGUF 模型", "*.gguf"), ...]`，`py_host.cpp:2556-2574`）⇒ 本插件现有写法可直接用。

### 1.3 线程闸门

- 门面方法**只许在宿主 UI 线程**调用；其它线程一律**返回 `None` + 记 Warn**（`py_host.cpp:3339-3363`），**不抛异常**。
- 跨线程白名单只有两项：`task_cancel_requested`、`on_ui_thread`（`widget_facade.cpp` 的 `kWorkerSafeMethods[]`）。
- `api.ui.on_ui_thread()` 是**查询**（返回 bool），不是投递器；唯一投递机制是 `api.ui.timer(parent, ms, cb)`。
- `api.log(message)` **可以**在工作线程调（写侧 `append_plugin_log_line` 带锁 + 200 行上限）。

### 1.4 日志

- `api.log(message)`：只写宿主插件日志缓冲（自动加 `[owner]` 前缀）—— **只有一个参数，没有 tag**。
- `api.ui.log(line)`：写宿主 LogView。
- `api.log_detail` **不存在**。
- 推荐 `ui.log_view(parent, height)` + `ui.log_view_append(view, line)`（一次一行，不 O(n²)）。

### 1.5 网络契约（最关键）

- 发行包**剥除** `_ssl.pyd` / `libssl-3.dll` / `libcrypto-3.dll` / `_sqlite3.pyd` / `sqlite3.dll` / `Qt6Network`（`scripts/package.ps1:488-502`）。
- ⇒ `import ssl`、`import urllib.request`、`import http.client` **全部 ModuleNotFoundError**（连 `http://127.0.0.1` 也不行）；`urllib.parse` 仍可用（纯字符串）。
- 官方参考：`plugins/_sdk/http_winhttp.py`（ctypes 调系统 `winhttp.dll`，零依赖；含"必须声明 `restype`，否则 64 位句柄被截断"的坑）。
- 宿主**不把** WinHTTP 暴露给插件；跨插件服务 `net.http_get/1` 是**可选的另一个插件**（`docs/2.0.0-跨插件服务契约.md`），能力只有"取一段文本"，**不支持** Range 断点续传 / POST / 进度 / 取消 ⇒ 本插件不能用它。
- 2.x 有「工具 → 联网功能」总开关，但**只管宿主自己的 HTTP**；插件自行联网不受约束（`docs/2.0.0-已知问题与范围_封测.md:27-29`）。

### 1.6 运行环境

- 嵌入式 CPython **3.14**（`py_host.h` 注释示例 `3.14.6`）。
- `csv / queue / threading / subprocess / zipfile / hashlib / socket / ctypes / json / re / tempfile / shutil / atexit` 均可用（只剥 ssl/sqlite3）。

## 3. 适配架构：单文件 + 三层薄适配

保持 **单文件**（1.x 只认 `plugins/*.py`，多文件在 1.x 不成立），把平台差异全部关进三个类：

```
plugins/ai_translate.py
├─ class _UiAdapter      # 门面：1.x 形状 → 2.x 实际签名；布局语义差异在这里消化
├─ class _Widget         # 句柄：把 1.x 的控件方法（set_text/configure/alive/...）翻成 api.ui.*
├─ class _ApiAdapter     # api.log(msg, tag) / api.log_detail(...) → api.log(msg)
└─ class AiTranslateTab  # 主体：只改 §4.4 列的 7 处逻辑，其余不动
```

### 3.1 `_UiAdapter`

- 构造时探测：`self.new = hasattr(api.ui, "on_ui_thread")`（2.x 独有）。
- 每个方法返回 `_Widget(raw)`（2.x 的 raw 是 `xrkit.Widget`）。
- 差异表：

| 1.x 写法（本插件现状） | `_UiAdapter` 在 2.x 的做法 |
|---|---|
| `pack(w, side=, fill=, expand=, padx=, pady=)` | **no-op**（宿主已自动排版；第一参在 2.x 是 parent，平移会挪错控件） |
| `row(parent, ...)` | **返回 `_Widget(parent)`**（不造容器；否则子控件重叠） |
| `set_state(w, "disabled"/"normal")` | `ui.set_enabled(w, state != "disabled")` |
| `button(..., state="disabled")` | `ui.button(..., enabled=False)`（丢掉 `state`） |
| `combo(parent, values, width=N, on_change=)` | 去掉 `width`，保留 `on_change` |
| `checkbox(parent, text, on_toggle=)` | 原样（`variable` 本插件未用） |
| `ask_yes_no(parent, title, message)` | 丢掉 `parent` |
| `ask_open_file(parent, title, filetypes=)` | 丢掉 `parent`；`filetypes` 原样（两元组列表，2.x 认） |
| `ask_save_file(parent, title, ...)` | 同上 |
| `ask_directory(title)` | 2.x 直接用；1.x 回退 `tkinter.filedialog` |

### 3.2 `_Widget`

实现 1.x 里用到的控件方法，2.x 下全部转 `api.ui.*`：

| 方法 | 2.x 落点 |
|---|---|
| `set_text(s)` / `setText(s)` | `ui.set_text(raw, s)` |
| `get_text()` | `ui.get_text(raw)` |
| `configure(text=s)` | `ui.set_text(raw, s)` |
| `configure(values=v)` | `combo_set_items`（见下：轮转） |
| `current(idx)` | 无对应 ⇒ 记录"期望索引"，由 `configure(values=)` 的轮转实现 |
| `currentText()` / `get()` | `ui.combo_value(raw)`（对 entry 用 `ui.get_text`） |
| `state(["selected"])` / `state(["!selected"])` | `ui.set_checked(raw, True/False)` |
| `instate(["selected"])` / `isChecked()` | `ui.checkbox_state(raw)` |
| `delete(0,"end")/insert(0,v)`、`delete("1.0","end")/insert("1.0",v)` | `ui.set_text(raw, v)`（1.x 的"先清后插"在 2.x 合成一次） |
| `alive()` | `ui.alive(raw)`（真判活） |
| `widget` 属性 | 返回 raw 本身（`pack` 已 no-op，仅保持旧调用不报错） |

**combo 选中项的绕行**（2.x 没有 `set_index`）：`configure(values=v)` 时把"期望索引"那一项**轮转到首位**再 `combo_set_items`，并把轮转后的顺序记进 `self._items`；同一组 values 重复设置时**短路不重建**（避免每次硬件检测都把下拉表重排）。外观代价：选定项永远显示在列表第一位。

### 3.3 `_ApiAdapter`

```python
def log(self, msg, tag="info"): self._api.log(("%s" % msg) if tag == "info" else "%s [%s]" % (msg, tag))
def log_detail(self, msg, tag="err"): self._api.log(msg)   # 2.x 无 detail 通道
```

### 3.4 线程与泵

```python
def ui_call(self, fn, *a, **k):
    if self._new_ui:
        if self.ui.on_ui_thread():          # 白名单方法，worker 可安全查
            self._invoke(fn, a, k)          # 异常 → _log_ui_error
        else:
            self._q.put((fn, a, k))
    else:
        ... 现有 1.x 逻辑不变 ...

def _pump(self):
    ... 现有 200 项 / 15ms 预算不变 ...
    if self._new_ui:
        return                              # 2.x：QTimer 自己重复，不重排
    top.after(30, self._pump)               # 1.x 原样
```

- `_reg()`：1.x 保留"取 Tk 顶层 + `after`"；2.x **只返回 `_Widget`**。
- 泵的启动点：`_build()` 末尾 `if self._new_ui: self.ui.timer(self.parent, 30, self._pump)`（`parent` 是宿主根容器，随页销毁）。
- `_ask_dir` 改走 `self.ui.ask_directory(title)`（2.x），1.x 保留 tkinter 回退。

### 3.5 状态缓存（消除跨线程读控件）

现状问题：
- `refresh_local_status()` 在 `ui_call(upd)` **之外**调 `self._persist_cfg()`（6592 行）⇒ worker 线程读 combo/entry。
- `current_tier()/current_variant()/find_model()/find_exe()` 直读 combo，会被 worker 调（`on_run`/`on_start`/`refresh_local_status`）。
- worker 里 3 处 `self.in_box.get_text()` / `out_box`（7185、7273、7412）。

改法（只动 5 个方法，不动调用方）：

1. `self.sel = {"variant": cfg["variant"], "tier": cfg["tier"], "ctx": str(cfg.get("custom_ctx", 8192)), "mode": cfg.get("mode","auto"), "lang": cfg.get("src_lang","auto")}`。
2. `combo(..., on_change=cb)` 在适配层**先**更新 `self.sel[key]` 再调 `cb`（`key` 由构造时的 `name=` 参数给出：`variant/tier/ctx/mode/lang/model_source/source`）。
3. `current_variant()/current_tier()` 改为**只读 `self.sel`**（UI 线程的 `_persist_cfg` 会同步它）。
4. `refresh_local_status()`：把 `self._persist_cfg()` **移进 `upd` 闭包第一行**；`upd` 里再刷新 `model_box`。
5. worker 里 3 处 `in_box.get_text()` → `self.cfg.get("in_dir")`（`_persist_cfg` 已维护）；`out_box.get_text()` 同理。
6. 9 个 checkbox 的 `on_toggle` 回写 `self.flags[...]`，`_chk_get` 在 worker 路径不再使用（`on_run` 读 `self.flags`）。

## 4. 逐项改造清单

### 4.1 元数据（41-50 行 + 7556 行）

### 4.6 网络（新增 `_Http` 实现，替换 5 处 urlopen）

在插件内新增约 250 行纯 ctypes 实现（不引外部文件，保持单文件）：

```text
class _Resp:            status / headers(dict, 小写键) / read(n) / close() / __enter__ / __exit__
class _HttpError(Exception)  code / reason
_http.get(url, headers=None, timeout=)   -> _Resp
_http.post(url, data: bytes, headers, timeout) -> _Resp
```

要求（按现有调用点逐条对齐）：

| 调用点 | 需要的语义 |
|---|---|
| 1713-1742 测速 | `Range: bytes=0-N`；读 `Content-Type`；`status == 206` 判定；按 64 KB 分块读到 `max_secs` |
| 1828-1868 下载 | `Range: bytes=have-`；`status==206` + `Content-Range: bytes a-b/total`；否则 `Content-Length` 且回退 `wb`；1 MB 分块 + 进度回调 + 取消位轮询 |
| 2314 /health | GET，5 s 超时，`status==200`，失败读 body 里的 `error` |
| 2380-2390 / 2521-2528 | POST JSON（`Content-Type: application/json`），读全部 body 再 `json.loads` |

实现要点（照抄 `_sdk/http_winhttp.py` 的教训）：
- 所有 `WinHttp*` 必须声明 `restype/argtypes`（`HINTERNET` 是 64 位句柄）；
- `WINHTTP_ACCESS_TYPE_AUTOMATIC_PROXY = 4`、禁止 https→http 降级；
- 分项超时四项都设成同一预算；
- 失败一律抛 `_HttpError`（带 Win32 错误码）/ `OSError`，替代 `urllib.error.HTTPError/URLError`；
- 删除 37-38 行 `import urllib.request/urllib.error`，保留 `urllib.parse`（1703 行仍在用）和 `socket`（2217 端口探测在用）。

### 4.7 删除 / 不再使用

- `subprocess`、`atexit`、`zipfile`、`hashlib`：保留（均可用）。
- `tkinter`：只在 1.x 回退里出现（`_ask_dir`），2.x 分支不再进入。
- `while ... top.after(...)`：仅 1.x 分支。
